# Vorlagen zur Weiterleitung

Freigegebene leere Vorlagen aus den am 10. Oktober 2026 bereitgestellten Dateien.
Pro Führungskräftepaket wird Reflexion unverändert beigelegt. Im Feedback werden
nur `fb_name_vg` und `fb_pn_vg` gefüllt; Dateiname:
`NameMA_Feedback_an_{NachnameVG}_{VornameVG}_{PersonalnummerVG}.docx`.
Eigene Vorlagen können über `reflection` und `feedback` in der Word-Konfiguration
hinterlegt werden. Ausgefüllte Dokumente gehören nicht in dieses Verzeichnis.
