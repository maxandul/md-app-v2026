Nach einer Änderung der JSON-Datei den Server beenden und neu starten. Prüfe bei fehlender Datei auch, ob Windows eine zusätzliche Endung «.txt» angehängt hat.

Word-Pakete werden automatisch auf dem Server gespeichert und von dort an Outlook übergeben. Herunterladen erzeugt nur eine zusätzliche Kopie. ZIP-Dateien gehören nicht in den Dossierordner; dort stellt die App Rücklauf-PDFs nach Prüfung und Freigabe automatisch bereit.
